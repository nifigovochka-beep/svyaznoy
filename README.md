# Связной

Мини-игра для телефона: довезти пакет до своих.

## Играть сейчас

Открой на телефоне:

https://htmlpreview.github.io/?https://github.com/nifigovochka-beep/svyaznoy/blob/main/index.html

Или скачай `index.html` и открой в Chrome.

## Управление
Влево / вправо. Газ идёт сам.

## Смысл
Довезти пакет до позиций. Упал — пакет не дошёл. Жетоны тратятся на резину, мотор и ремнабор.
