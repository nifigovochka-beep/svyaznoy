# Связной

Мини-игра для телефона: довезти пакет до своих.

Репозиторий — единственный источник правды. Дорабатывать можно в любом ИИ: открой репо → читай `CONCEPT.md` + `index.html`.

## Играть

https://htmlpreview.github.io/?https://github.com/nifigovochka-beep/svyaznoy/blob/main/index.html

Или скачай `index.html` и открой в Chrome на телефоне.

## Файлы
- `index.html` — вся игра
- `CONCEPT.md` — смысл, зоны, магазин, правила доработки
